GitHub + Vercel + Vercel Blob Deployment Blueprint

1. Project Repository Folder Structure

Organize your GitHub repository as follows for automatic Vercel serverless build:

my-broadcast-academy/
├── api/
│   ├── upload.js          # Vercel Serverless Endpoint for `@vercel/blob` uploads
│   └── content.js         # API route to fetch/update video metadata
├── index.html             # Frontend SPA (This document)
├── vercel.json            # Deployment routing configuration
└── package.json           # Dependencies (@vercel/blob, @vercel/kv)

2. Vercel Serverless Upload Handler (`api/upload.js`)

Use this serverless code in Vercel to store media directly in Vercel Blob storage safely with password checking:

import { put } from '@vercel/blob';

export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).json({ error: 'Method not allowed' });
  
  // Verify Admin Auth Header
  const authHeader = req.headers.authorization;
  if (authHeader !== `Bearer ${process.env.ADMIN_PASSWORD}`) {
    return res.status(401).json({ error: 'Unauthorized admin access' });
  }

  const { filename, contentType } = req.query;
  const blob = await put(filename, req, {
    access: 'public',
    contentType
  });

  return res.status(200).json(blob); // Returns { url: "https://...public.blob.vercel-storage.com/..." }
}

3. GitHub to Vercel Publishing Workflow

  1. Initialize Git: git init && git add . && git commit -m "Initial Broadcast Academy commit"
  2. Push code to your GitHub Repository.
  3. Log into Vercel.com, click Add New Project, and import your GitHub repo.
  4. In Vercel Dashboard, navigate to Storage → Create Vercel Blob Database.
  5. Add Environment Variables in Vercel settings:
      >BLOB_READ_WRITE_TOKEN (Auto-linked by Vercel) >ADMIN_PASSWORD (Set your production admin password)
  6. Click Deploy. Your public training platform will be live globally on Vercel CDN.
